## How to use it (about 30 minutes)
1. Open Metabase and Grafana side by side. Start with the rows marked **Compare today** (about a dozen).
2. For each row: open the v1 card, open the v3 panel, check the "should match" line, then read the "expected to differ" line before judging a gap.
3. Rows marked **Partial** have a window longer than the data held; compare the shape only. Rows marked **Fills later** are empty or nearly empty on purpose.
4. Tell Emma anything that is outside the expected differences. Unexpected gaps become issues.
